# Shared work tracker

Built at athenahealth using Microsoft Lists and Power Automate.

The team needed one place for operational work that required follow-through without the overhead of a formal project. I gathered input on the fields, statuses and notifications the team needed, then designed and delivered the tracker with automated updates.

The work covered stakeholder input, tracking fields, workflow configuration and team-level implementation. The tracker was delivered for team use. No measured time savings are claimed.

This is a description of professional experience. Internal records, screenshots and automation exports are not included.
